    GitHub issue and PR view

    Lists open issues and pull requests across public GitHub organizations and repositories. Select a column header to sort the loaded rows.

    Filters

    • Repositories: comma-separated organization/* or owner/repository selectors.
    • Exclude repositories: comma-separated owner/repository selectors. Exclusions always win.
    • Type: issues, pull requests, or both.
    • Filters are stored in the repos, exclude, and type URL parameters; repos and exclude may repeat.

    Always excluded

    • Archived repositories.
    • Closed issues; closed, merged, and draft pull requests.
    • Pull requests titled WIP, work in progress, draft, DNM, or do not merge. Markers match case-insensitively in brackets or parentheses, or at the start of a title. Issues are not filtered by title.

    Limits

    • Requests are unauthenticated, paced, and never polled automatically.
    • Counts reflect filters, not GitHub's unfiltered total.
